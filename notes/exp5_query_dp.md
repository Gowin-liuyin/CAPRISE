## 1. Theorem 1 公式与本文的精确含义

论文 Eq.21：

```
k' = k + m · (Ω_{n-1}(π)/Ω_n(π)) · ∫_{α_k}^{α_k'} sin^{n-2}θ dθ ,
     α_k' = α_k + Δα_k ,  Ω_n(π) = 2π^{n/2}/Γ(n/2)
```

推导（与论文公式本体逐项核对，无改动）：

- 均匀 n 维单位球面上，随机方向与固定 query 的夹角 θ 的密度 ∝ sin^{n−2}θ，
  其归一化常数恰为 Ω_n(π)，故
  `(Ω_{n-1}/Ω_n)∫_0^α sin^{n-2}θ dθ = P(θ ≤ α) =: F(α)`。
- 因此 Eq.21 的积分项 = m·(F(α_k+Δα_k) − F(α_k))。又 α_k 定义隐含 F(α_k)=k/m，
  即 m·F(α_k)=k，于是 **Eq.21 等价于**

  ```
  k' = m · F(α_k + Δα_k)                                              (Eq.21')
  ```

  这是一个干净的恒等式，也是门禁①/②的检验对象。
- 几何含义：`k'−k` 是"把角帽半径从 α_k 扩张到 α_k+Δα_k 后，壳层内的**期望点数**"。
  更具体地说：原始 top-k 都在以 query 为中心、半径 α_k 的角帽内；query 被扰动 Δα_k 后，
  这些点都落在以**扰动后 query** 为中心、半径 α_k+Δα_k 的角帽内（三角不等式，最坏方位角），
  所以取 `ceil(Eq.21)` 个候选**一定**包含原 top-k。**注意：这是充分（最坏情况）上界，
  不是实际检索所需的最小 k'**（见 §5.3 的实测，这一区别是本复现的核心 finding A10b/F9）。
- RemoteRAG 的约定 "Δα_k can be approximately by r"：对单位向量 q，
  `ρ = angle(q, q+r u) = arccos((1+r·q·u)/‖q+ru‖) = 2 arcsin(r/2) ≈ r`（r ≤ 0.033 时相对差 <1e-4），
  故正文/RemoteRAG 用 **Δα_k ≈ r**。Table III 的 r=0.033/0.02 据此换算成角度。

### 1.1 Beta 形式（数值稳定的唯一可行实现）

```
F(α) = P(θ ≤ α) = 1 − I_{(1+cos α)/2}((n−1)/2, (n−1)/2)      # I_x = 正则化不完全 Beta
α_k  = F^{-1}(k/m) = arccos(2·I^{-1}_{1−k/m}(a,a) − 1),  a=(n−1)/2
```

为什么必须用 Beta（`results/exp5_query_dp.json → numerical_stability` 的实测证据）：

| 问题 | 直接按 Eq.21 数值积分 | Beta 形式 |
|---|---|---|
| 积分核 sin^{n−2}θ 在 float64 下溢 | n=768, θ=0.05：`sin^766(0.05)=0.0`（log10 理论值 −996.7）；n=1536, θ=0.1：0.0（log10 −1535.1）；n=4096, θ=0.3：0.0（log10 −2167.4） | 有限：F 值正常（如 F(0.05,768) 可计算）|
| 小 n 时与直接积分对照 | n∈{10,50,100}, k∈{5,20}：max \|quadrature − Beta\| = **1.1e-16** | 一致 |
| 反解精度 | — | F(F^{-1}(f))=f，f∈[1e-5,0.9]、n∈{768,1536,4096}：max 相对误差 **4.55e-12** |
| 定义自洽 | — | max \|m·F(α_k) − k\| = **2.2e-12**（16 格）|
| 尾部（n=1536, k/m=5e-5） | — | 无 NaN/inf，k' 有限且 >k；n 到 3072/4096 亦有限 |

（scipy `betainc/betaincinv` 在 a≈767.5、x≈0.55 处稳定；`1−k/m` 的减法在 k/m≥5e-5 时
保留 ~11 位有效数字，远优于直接积分。）

## 4. 约定探查：哪种实现对得上论文表？

`convention_probe` 用同一组 Table III 单元测试 3 种候选约定（论文/预测比值，越接近 1 越吻合）：

| 约定 | 预测方式 | 论文/预测 mean | 范围 |
|---|---|---|---|
| 角度空间 Δα=r（正文/RemoteRAG） | k'=m·F(α_k+r) | 1.770 | 1.357–2.250 |
| 角度空间 Δα=1.2r | k'=m·F(α_k+1.2r) | **1.042** | 0.894–1.295 |
| 距离空间 d_k'=d_k+r（弦长加 r，再转角度） | α'=2asin((d_k+r)/2), k'=m·F(α') | 0.717 | 0.585–0.893 |

结论：**1.2r 的角度约定最接近论文表**，但 16 格残差仍达 ±15–30%，无法用"固定常数倍 Δα"精确复现；
距离空间约定则系统性偏低。论文未给出生成 Table III 的脚本/数据分布，因此**无法确定表值的精确来源**，
但可以确定它**不是**正文所述 `Δα≈r` 的 Eq.21 直算结果。→ **finding A10**。

## 5. Monte-Carlo 验证（m=100,000，固定 DB，每维 200 个随机 query）

### 5.1 协议

- DB：m=100,000 个**均匀单位球面**随机向量（n=768/1536），用固定种子分块确定性地生成，
  **同一 DB 复用于所有 query**（模拟真实检索）；不物化 m×d 全矩阵（分块 + 两遍距离计算）。
- query：nq=200 个随机单位向量；每个 query 用 DistanceDP 扰动 `q̃ = q + r·u`，u 球面均匀，
  **不重新归一化**（‖q̃‖≠1，按 RemoteRAG 定义）；r=0.033、0.02 分别独立扰动。
- 每格记录 4 个量：
  1. `cap_pop`：以 q̃ 为中心、半径 α_k+r 的角帽内 DB 点数，α_k=F^{-1}(k/m)（论文定义）→ Eq.21 的期望点数；
  2. `cap_emp`：同上，但 α_k 用该 query 实际第 k 近邻的夹角（端到端经验版）；
  3. `min_k'`：真实检索所需最小 k' = 原 top-k 在 q̃ 排序下的最坏名次（`np.argpartition` 求阈值后计数）；
  4. `coverage`：真实取 `ceil(Eq.21)` 个候选时，是否包含原 top-k。
- 统计量：cap 点数与 Eq.21 的相对偏差；min_k' 的 mean/median/std/**p95/p99**/max；松弛度与覆盖率。

### 5.2 MC 与 Eq.21(Δα=r) 的一致性（门禁②）

（全 16 格最大 \|偏差\| = **2.38% < 5%**；用经验 α_k 的版本最大 \|偏差\| = **2.12% < 5%**。）
→ Eq.21 作为"扩张角帽期望点数"的数学恒等式**被 MC 验证**（偏差来自有限 m、有限 query 数的采样噪声，
n=768 的 −1.5%~−2.4% 系统性负偏与 200 个 query 上帽点数的抽样波动一致）。

（这直接验证了 Theorem 1 的"保证包含"主张，但前提是接受其最坏方位角推导；见 5.3 的宽松度）。

关键结论：

1. **实测最小 k' ≈ k + 少量**（k=5 → 5.3–5.5；k=20 → 21.2–22.5），而不是论文表中的 52×、196× 之类。
   原因：高维下随机扰动方向与"某 DB 点 − q"的差向量近似正交（夹角 ~π/2），
   单个点距离的典型改变只有 **O(r/√n)**（n=768, r=0.033 时 ≈1.2e-3），与最近邻间距同量级，
   所以只有极少数点换位；而 Eq.21 的 α_k+r 是最坏方位角（扰动完全沿该点方向）的保守界。
2. **松弛度** = 公式 k' / 实测最小 k'：随 n 增大而增大（1536 比 768 大 3–4 倍）、随 k 增大略降、
   随 r 增大而增大（r=0.033 约为 r=0.02 的 2–4 倍）。mean 松弛度 6.7×–85.6×，p99 松弛度 5.5×–58.8×。
   在门禁要求的例子里：n=768, r=0.033, k=5 → k'=公式 147.25 vs mean 5.53（26.6×）、p99 8.01（**18.4×**）。
3. **实用建议**（若按定理推导的均匀球面模型部署）：`k' = max(k, ceil(p99))`，即 k'=7–31（视 n,r,k），
   比 Eq.21 的 42–1237 小 1–2 个数量级；这只是"该模型下的经验充分值"，真实各向异性嵌入数据需另行标定。
4. 论文 Table III 的扩张（k=5 时 52×/196×）**同时大于** Eq.21(Δα=r)（29.5×/94.4×）与实测最小 k'（≈1×）：
   它既不是最小扩张，也不是正文约定下的定理值 → 进一步支持 A10（论文表值另有来源/约定）。

## 6. 结论与 finding 登记

### Finding A10（重要，论文内部不一致）

- Table III 的 top-k' 无法由 Eq.21 + RemoteRAG 的 `Δα≈r` 复现：公式值为论文的 **0.444–0.737 倍**；
  逐格反推需 `Δα/r = 1.213 ± 0.044`（range 1.154–1.298，16 格全部 >1.15）。
- 说明论文 Table III 的生成约定与其正文/RemoteRAG 的"Δα_k ≈ r"表述不一致（可能另有数据分布/
  距离空间约定/实现细节，论文未给出，无法唯一确定）。
- 处理：报告中**并排给出** 论文表 / Δα=r / Δα=1.2r / 反推 Δα/r；不强行对齐；论文表值不参与门禁判定。

### Finding A10b（F9，定理性质）

- Eq.21 是**充分但极宽松**的上界：均匀球面数据上实测最小 k' ≈ k（mean 5.3–22.5），
  公式（及论文表）高估 6.7×–85.6×（mean 松弛度）；`ceil(Eq.21)` 的覆盖率 = 100%。
- 报告应明确区分"定理的期望扩张上界"与"实际检索所需 k'"，避免把论文表的 52× 解释成实际扩张需求。

### 对 claim/table 的影响（供 `docs/CLAIMS_CHECKLIST.md` 更新）

- C7（Theorem 1 公式正确）：**公式本体成立**（Beta 形式与直接积分一致 1e-16；MC 对扩张帽点数
  偏差 <2.4% <5%；ceil(Eq.21) 覆盖率 100%）→ 可标 ✅（含"充分非必要、上界宽松"说明）。
- C10（DistanceDP）：**机制实现正确**（M12 门禁 PASS）→ 可标 ✅。

- P4（r↑ ⇒ k'↑ 的 trade-off 趋势）：**趋势成立**（Eq.21 与 MC 最小 k' 均随 r 增大单调增），
  但论文 Table III 的绝对比值不可复现。

## 7. 限制与未解问题

1. MC 使用**均匀球面随机向量**（定理的假设分布）；真实 GTR/MS MARCO 嵌入是各向异性/聚类的，
   最近邻间距分布完全不同（真实数据上扰动影响可能更大），因此 §5.3 的"最小 k'≈k"只适用于定理假设模型，
   不能外推到真实数据；真实数据上的 DP 影响应在 exp2（M18）里用真实嵌入评估。
2. 论文未给 Table III 的生成代码/原始数据/随机性说明，故 A10 只能证明"与正文 Δα≈r 不一致"，
   不能证明论文具体用了哪种实现。
3. 论文 Eq.21 的 k' 是期望值/上界，但论文把表值当作可直接使用的 k'；二者语义差异已在 A10b 记录。
4. **门禁内 MC 的独立性（交叉验收 V5）**：`gates/gate_m13_theorem1.py` 里的 reduced MC 通过
   importlib 复用 `experiments/exp5_query_dp.py:monte_carlo`（同一实现），属于**回归检查**，
   不是独立实现；实现级独立性由单独的交叉验收任务覆盖（`results/verify_theory.json` /
   `notes/verify_theory.md`，m=20000、nq=20 的独立 MC 偏差 −1.99%）。
