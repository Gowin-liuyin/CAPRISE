## 1. Theorem 1 公式与本文的精确含义

论文 Eq.21：

```
k' = k + m · (Ω_{n-1}(π)/Ω_n(π)) · ∫_{α_k}^{α_k'} sin^{n-2}θ dθ ,
     α_k' = α_k + Δα_k ,  Ω_n(π) = 2π^{n/2}/Γ(n/2)
```

推导（与论文公式本体逐项核对，无改动）：

- 均匀 n 维单位球面上，随机方向与固定 query 的夹角 θ 的密度 ∝ sin^{n−2}θ，
  其归一化常数恰为 Ω_n(π)，故
  `(Ω_{n-1}/Ω_n)∫_0^α sin^{n-2}θ dθ = P(θ ≤ α) =: F(α)`。
- 因此 Eq.21 的积分项 = m·(F(α_k+Δα_k) − F(α_k))。又 α_k 定义隐含 F(α_k)=k/m，
  即 m·F(α_k)=k，于是 **Eq.21 等价于**

  ```
  k' = m · F(α_k + Δα_k)                                              (Eq.21')
  ```

  这是一个干净的恒等式，也是门禁①/②的检验对象。
- 几何含义：`k'−k` 是"把角帽半径从 α_k 扩张到 α_k+Δα_k 后，壳层内的**期望点数**"。
  更具体地说：原始 top-k 都在以 query 为中心、半径 α_k 的角帽内；query 被扰动 Δα_k 后，
  这些点都落在以**扰动后 query** 为中心、半径 α_k+Δα_k 的角帽内（三角不等式，最坏方位角），
  所以取 `ceil(Eq.21)` 个候选**一定**包含原 top-k。**注意：这是充分（最坏情况）上界，
  不是实际检索所需的最小 k'**（见 §6.3 的实测，这一区别是本复现的核心 finding A10b/F9）。
- RemoteRAG 的约定 "Δα_k can be approximately by r"：对单位向量 q，
  `ρ = angle(q, q+r u) = arccos((1+r·q·u)/‖q+ru‖) = 2 arcsin(r/2) ≈ r`（r ≤ 0.033 时相对差 <1e-4），
  故正文/RemoteRAG 用 **Δα_k ≈ r**。Table III 的 r=0.033/0.02 据此换算成角度。
- 但论文 §V-4 只说 "we perturb the query embedding with r ... as described in Equation 21"，
  **没有定义 r 与 Δα_k 的换算**。因此 §4 把可能的换算约定逐格枚举，检验哪个能复现 Table III。

### 1.1 Beta 形式（数值稳定的唯一可行实现）

```
F(α) = P(θ ≤ α) = 1 − I_{(1+cos α)/2}((n−1)/2, (n−1)/2)      # I_x = 正则化不完全 Beta
α_k  = F^{-1}(k/m) = arccos(2·I^{-1}_{1−k/m}(a,a) − 1),  a=(n−1)/2
```

为什么必须用 Beta（`results/exp5_query_dp.json → numerical_stability` 的实测证据）：

| 问题 | 直接按 Eq.21 数值积分 | Beta 形式 |
|---|---|---|
| 积分核 sin^{n−2}θ 在 float64 下溢 | n=768, θ=0.05：`sin^766(0.05)=0.0`（log10 理论值 −996.7）；n=1536, θ=0.1：0.0（log10 −1535.1）；n=4096, θ=0.3：0.0（log10 −2167.4） | 有限：F 值正常（如 F(0.05,768) 可计算）|
| 小 n 时与直接积分对照 | n∈{10,50,100}, k∈{5,20}：max \|quadrature − Beta\| = **1.1e-16** | 一致 |
| 反解精度 | — | F(F^{-1}(f))=f，f∈[1e-5,0.9]、n∈{768,1536,4096}：max 相对误差 **4.55e-12** |
| 定义自洽 | — | max \|m·F(α_k) − k\| = **2.2e-12**（16 格）|
| 尾部（n=1536, k/m=5e-5） | — | 无 NaN/inf，k' 有限且 >k；n 到 3072/4096 亦有限 |

（scipy `betainc/betaincinv` 在 a≈767.5、x≈0.55 处稳定；`1−k/m` 的减法在 k/m≥5e-5 时
保留 ~11 位有效数字，远优于直接积分。）

## 4. 四种 Δα 约定系统枚举（task-3）

### 4.1 四种约定的精确定义

对每个 Table III 单元（m=100,000，α_k = F^{-1}(k/m)）：

| 约定 | 定义 | 来源/含义 |
|---|---|---|
| (a) | `Δα = r` | RemoteRAG §3.2.2 的文字近似（"Δα_k ... can be approximately by r"） |
| (b) | `Δα = 2·asin(r/2)` | 单位球面上欧氏位移 r 对应的**角**偏差（弦长 2sin(Δα/2)=r）；与 (a) 相差 <0.02% |
| (c) | `α_k' = 2·asin((2·sin(α_k/2)+r)/2)`，`Δα = α_k'−α_k` | 欧氏扩张约定：第 k 近邻的**弦长** `d_k=2sin(α_k/2)` 增加 r（query 点欧氏外移 r 的最坏情形），再换回角度 |
| (d) | 逐格反解 `Δα` 使 Eq.21 等于论文表值 | 表值隐含、论文未声明的约定（拟合值，不是"正确值"） |

`(a)` 与 `(b)` 的数值差 <0.02%（r≤0.033 时 `2asin(r/2)=r+r³/24+…`），故下表中两者几乎相同；
`(c)` 的等效角扰动 `Δα/r = 1.332–1.369`（16 格，mean 1.351），**不是** 1。

## 5. 参照实现交叉验证：RemoteRAG §5.4 / Fig.5(c)（task-3）

### 5.1 参照点与原文出处

被引用的实现是 RemoteRAG (arXiv:2412.12775v1)，其 Lemma 1 / Theorem 1 与本文 Eq.21 同式：

- §3.2.2 原文：*"Since the perturbation is small (r ≪ 1), the perturbed angle Δα_k between e_k
  and e_{k'} can be approximately by r."*（即 **Δα_k ≈ r**）
- §5.4 Efficiency Study 原文：*"We highlight k'=160, r=0.03 in Fig. 5(c) ..."*；
  Fig.5(c) caption：*"Cost breakdown (k'=160)."*
- 嵌入模型 T5 → n=768，k=5（§5.3/§5.4 固定 k=5）。

**参照点**：k=5, r=0.03, n=768 → **k'=160**。
**口径说明**：§5.4 未声明该点的 N；附录 B.4 的默认设置写 "N=10^5, k=5, k'=160"。
但用 Δα=r 复算：N=10^5 只给出 111.89，**远小于 160**；N=10^6 给出 170.34（+6.46%）。
故本交叉验证取 **N=10^6（由结果反推）**；且 r 只给到两位小数（0.03 ∈ [0.025, 0.035)）。

### 5.2 复算结果（JSON: `remoterag_reference.evaluations`）

| N | (a) Δα=r | (b) chord | (c) euclid | Δα=1.213r | 相对 160（a 列） |
|---|---|---|---|---|---|
| 10^4 | 69.92 | 69.92 | 151.20 | 112.87 | −56.30% |
| 10^5 | 111.89 | 111.90 | 274.67 | 199.20 | −30.07% |
| 10^6 | **170.34** | 170.36 | 464.69 | 331.14 | **+6.46%** |

（`Δα=1.213r` 列用第 3 节反解出的 mean 1.2128519777 作为常数。）

### 5.3 反解与判读

- **主判据**：N=10^6 时 `Δα=r` → 170.34 vs 参照 160，**相对误差 6.46% ≤ 10%** 门禁线。
- **点态反解**：把 Δα 当未知数解 `k'=160`（N=1e6），得 `Δα = 0.029413 rad`，
  即 **Δα/r = 0.9804**（r*=0.02941，仅比标称 0.03 低 2%）；|Δα/r−1| = 0.020 < 0.05。
  这直接说明参照点与 **Δα=r** 自洽。
- **同一参照点排除其它约定**：`Δα=1.213r` → 331.14（**2.07×** 参照值）；欧氏扩张 (c)
  → 464.69（**2.90×**）。二者都被参照实现排除，故交叉验证的结论只能是 "Δα=r 与被引用实现一致"。
- **结论（按任务要求的口径）**：**Δα=r 与参照实现一致（约 6%）**——被引用的 RemoteRAG 实现
  确实按 `Δα≈r` 计算；但**这不能支持论文 Table III**（后者需要 1.21r，见 §4）。
- **简并性/限制（必须随结论一起引用）**：
  1. N 未与 k'=160 同时声明：`(N=10^6, r=0.02941)` 与 `(N=10^5, r=0.03392)` 都能给出 160，
     二者都在 r 的两位小数舍入范围内；参照点无法区分它们（见 `remoterag_reference.inversions`）。
  2. 附录 B.4 自己的默认 "N=10^5, k=5, k'=160" 与按 Δα=r 的公式值 111.89 不自洽，
     说明 k'=160 更像**选定的实验超参数**而非由公式反算；因此交叉验证只能证明
     "Δα=r 与被引实现的量级/口径一致（约 6%）"，不能证明其逐位实现一致。

## 6. Monte-Carlo 验证（m=100,000，固定 DB，每维 200 个随机 query）

### 6.1 协议

- DB：m=100,000 个**均匀单位球面**随机向量（n=768/1536），用固定种子分块确定性地生成，
  **同一 DB 复用于所有 query**（模拟真实检索）；不物化 m×d 全矩阵（分块 + 两遍距离计算）。
- query：nq=200 个随机单位向量；每个 query 用 DistanceDP 扰动 `q̃ = q + r·u`，u 球面均匀，
  **不重新归一化**（‖q̃‖≠1，按 RemoteRAG 定义）；r=0.033、0.02 分别独立扰动。
- 每格记录 4 个量：
  1. `cap_pop`：以 q̃ 为中心、半径 α_k+r 的角帽内 DB 点数，α_k=F^{-1}(k/m)（论文定义）→ Eq.21 的期望点数；
  2. `cap_emp`：同上，但 α_k 用该 query 实际第 k 近邻的夹角（端到端经验版）；
  3. `min_k'`：真实检索所需最小 k' = 原 top-k 在 q̃ 排序下的最坏名次（`np.argpartition` 求阈值后计数）；
  4. `coverage`：真实取 `ceil(Eq.21)` 个候选时，是否包含原 top-k。
- 统计量：cap 点数与 Eq.21 的相对偏差；min_k' 的 mean/median/std/**p95/p99**/max；松弛度与覆盖率。

### 6.2 MC 与 Eq.21(Δα=r) 的一致性（门禁②）

### Finding A10（重要，论文内部不一致）

### Finding A10c（四约定枚举，task-3）

- 对 16 格枚举 `Δα` 的四种约定（见 §4）：**(a) Δα=r / (b) 2asin(r/2) / (c) 欧氏扩张 /
  (d) 逐格反解**。(a)(b) 相差 <0.02%；(c) 的等效 `Δα/r=1.332–1.369`。

  (a) −55.6%…−26.3%，(c) +12.0%…+71.1%。
- 只有 **(d)** 精确复现（|rel err| ≤5.6e-14），其 `Δα/r = 1.1537–1.2977`（mean 1.2129、std 0.0435）
  在任何论文文字中都没有声明 → **表值隐含约定 (d)，而正文/公式/RemoteRAG 都推不出它**。

## 8. 限制与未解问题

1. MC 使用**均匀球面随机向量**（定理的假设分布）；真实 GTR/MS MARCO 嵌入是各向异性/聚类的，
   最近邻间距分布完全不同（真实数据上扰动影响可能更大），因此 §6.3 的"最小 k'≈k"只适用于定理假设模型，
   不能外推到真实数据；真实数据上的 DP 影响应在 exp2（M18）里用真实嵌入评估。
2. 论文未给 Table III 的生成代码/原始数据/随机性说明，故 A10 只能证明"与正文 Δα≈r 不一致"，
   不能证明论文具体用了哪种实现。
3. 论文 Eq.21 的 k' 是期望值/上界，但论文把表值当作可直接使用的 k'；二者语义差异已在 A10b 记录。
4. **参照实现交叉验证的精度上限**：RemoteRAG §5.4 未声明 k'=160 对应的 N，r 只写两位小数；
   `(N=1e6, r=0.02941)` 与 `(N=1e5, r=0.03392)` 都能给出 160，且其附录 B.4 的默认
   "N=10^5, k=5, k'=160" 与按 Δα=r 的公式值 111.89 不自洽。故 A10d 只能证明
   "Δα=r 与被引实现的量级/口径一致（约 6%）"，不能证明逐位一致。
5. 四约定枚举中的 (c) 采用"弦长增加 r"的最坏情形读法；若 query 的欧氏位移方向与
   该 DB 点不共线，角变化更小（≤(c)），故 (c) 本身已是对"欧氏外移 r"的保守读法，
   它仍高估表值 12%–71%，结论不变。
6. **门禁内 MC 的独立性（交叉验收 V5）**：`gates/gate_m13_theorem1.py` 里的 reduced MC 通过
   importlib 复用 `experiments/exp5_query_dp.py:monte_carlo`（同一实现），属于**回归检查**，
   不是独立实现；实现级独立性由单独的交叉验收任务覆盖（`results/verify_theory.json` /
   `notes/verify_theory.md`，m=20000、nq=20 的独立 MC 偏差 −1.99%）。
   本次新增的 (a)/(b)/(c)/(d) 与 RemoteRAG 断言则是由门禁**独立重算**（scipy brentq + Beta CDF），
   不是读回 JSON 里的期望值。
