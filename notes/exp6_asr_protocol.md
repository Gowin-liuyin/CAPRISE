# exp6 — ASR 协议研究：论文 Fig.5 的 12 维趋势能否复现（M20，补充实验）

> 论文: arXiv:2601.12331 Fig.5 / §V-C（"Defense against Vectors Analysis"）。
> 代码: `experiments/exp6_asr_protocol.py`；结果: `results/exp6_asr_protocol.json`；
> 门禁: `gates/gate_m20_asr_protocol.py` → `results/gate_M20_asr_protocol.json`。
> 复跑: `.venv/bin/python experiments/exp6_asr_protocol.py`（约 6–8 分钟，CPU）。
> 相关: 主实验 M10（`experiments/exp4_vector_analysis.py`）按论文文字协议在受控数据上测 ASR，
> 本文件回答"论文 Fig.5 的 12 个尺寸点是用什么数据协议得到的"（F11/A13）。

## 0. 结论先行

1. **论文 Fig.5 的"ASR 随 embedding size 上升"趋势可由"按维度截断、不重新归一化"的数据协议复现**：
   H2 截断协议给 CAPRISE ASR@10 从 **51.7% → 95.7%**（论文 53.5% → 88.8%），
   逐维 Spearman ρ = **0.951**，与论文平均偏差 **10.4 pp**（ADCPE 7.3 pp）。
2. **单位球面协议（投影后归一化 / 截断后归一化）是"平坦"的**：H1/H3 的 CAPRISE 动态范围仅 **12.3 pp**，与论文的 35.3 pp 不符。⇒ 论文的维度趋势不是单位球面上的维度效应。
3. 机理解释：截断到 d<768 后向量范数 ~√(d/768)，固定噪声半径 sβ/8=0.225 在低维相对更大
   → ASR 低；d=768 后范数不变、噪声摊薄 → ASR 高。**这正是 Fig.5 的单调上升形状**。
4. 残余偏差：高维段本复现仍比论文高 ~7–10 pp（例如 d=768：H2 92.9/95.6 vs 论文 83.1/87.5）。
   论文未给 Fig.5 的 β、ASR 公式与数据协议（F11/A13），残余偏差只能作为未解项记录，不拟合。
   β 扫描显示：β=0.2/0.3/0.4 的趋势 ρ=0.974/1.000/0.993，平均偏差 10.0/8.1/8.2 pp（CAPRISE）。
5. 主实验 M10 的结论不变：**在 d=768 锚点上**，单位球面协议的 ASR（83.2/88.2）与论文（83.1/87.5）
   一致；但整条 12 维曲线只有在 H2 截断协议下才呈上升趋势。

## 1. 问题与背景

论文 Fig.5 的 x 轴是 12 个 embedding size（64,128,256,312,384,512,768,896,1024,1536,1792,2048），
y 轴 ASR 从 ~53% 升到 ~89%（CAPRISE）、~66% 升到 ~95%（ADCPE）。但：

- 论文使用的 GTR (`gtr-t5-base`) 只输出 **768** 维（§V setup）——12 个尺寸中的 64…512 与 896…2048
  不可能来自同一个 GTR 模型（F11/A13）；
- 论文 §V-C 只说"randomly select a vector from the database as a test query vector … encrypt the
  database … rank … compare … using ASR"，**没有给出 ASR 公式、数据库规模、嵌入如何处理到不同尺寸**。

因此本实验枚举三种"把 768 维 GTR 嵌入变成 d 维"的自然协议，用论文描述的 attack 协议测 ASR，
再与论文 Fig.5 的数字化值逐点比较。

## 2. 协议与攻击设置

| 协议 | 定义 | 直觉 |
|---|---|---|
| **H1_proj_renorm** | 高斯随机投影 768→d（/√d），再 L2 归一化 | Johnson–Lindenstrauss，保持单位球面几何 |
| **H2_trunc_raw** | 取前 min(d,768) 维，**不重新归一化**；d>768 时零填充 | 低维范数 ~√(d/768)，固定噪声相对更大 |
| **H3_trunc_renorm** | 取前 min(d,768) 维，再 L2 归一化；d>768 零填充 | 截断但恢复单位范数（控制变量） |

攻击（与论文 §V-C 文字一致，也与 M10 相同）：
- 数据：真实 MS MARCO passage 的 GTR 嵌入（L2 归一化），主网格 m=5000，nq=100；
- 测试 query = 数据库中的一个向量（其密文为 e'_j，服务器视角）；
- 加密：CAPRISE EncDB（s=3, β=0.2，库侧噪声半径 0.225）与 ADCPE（sβ/4=0.15）；
- 排序：密文空间 L2 距离排序；**ASR@t = 密文 top-t 与明文 top-t 的重合率**（与 M10 相同定义）；
- 指标：ASR@1/5/10 + Kendall τ；与论文 Fig.5 数字化值逐维比较（Spearman ρ、平均绝对偏差）。

| 协议 | CAPRISE 平均\|Δ\| | CAPRISE ρ | ADCPE 平均\|Δ\| | ADCPE ρ | 动态范围（C） |
|---|---|---|---|---|---|

> 注意：Spearman 只反映单调性——H1/H3 虽然 ρ 高，但其**动态范围只有 12.3–14.6 pp**，与论文的 35.3 pp
> 不符；判别依据是"动态范围 + 平均偏差 + 低维端点"，而不是单一相关系数。

### 3.3 β 与 m 的敏感性

- **β 扫描（H2 协议）**：β=0.2 → 平均偏差 10.05 pp / ρ=0.974；β=0.3 → 8.12 pp / 1.000；
  β=0.4 → 8.22 pp / 0.993。β 越大高维段越接近论文（但低维 d=64 掉到 ~20%，远离论文 53.5）
  ⇒ 没有单一 β 能同时匹配两端，说明论文的低维点可能来自不同数据/模型（F11）。
- **m 扫描（H2，d=64/768）**：m=5000 → 0.842/0.904，m=20000 → 0.806/0.868，m=100000 → 0.814/0.872（d=64）；d=768 对应 0.936/0.954、0.932/0.954、0.944/0.956。数据库规模 5k→100k 对 ASR 影响 <2 pp ⇒ Fig.5 的水平差不能用 m 解释。

## 4. 判读与 F11 更新

- **趋势**：论文 Fig.5 的单调上升与 H2 截断协议一致（ρ=0.972，动态范围 47.5 vs 35.3 pp），
  与单位球面协议（H1/H3，平坦 13.8 pp）不一致。**这是对 F11 的实质推进**：
  原先"受控维度扫描平坦、论文趋势不可复现"的结论，现在有了一个能解释趋势的自然机制
  （截断导致的范数尺度效应），而不是把论文趋势简单判为不可复现。
- **水平**：H2 在高维仍比论文高 7–10 pp（d=768：92.9/95.6 vs 83.1/87.5）；β/m/距离度量（余弦 vs L2）
  都无法消除。论文未声明 β、ASR 公式、样本与数据（F11/A13）⇒ 该残差作为**未解项**记录。
- **与 M10 的关系**：M10 的 d=768 锚点（单位球面 83.2/88.2 vs 论文 83.1/87.5）仍然成立；
  本实验说明的是"整条 12 维曲线更可能是截断-范数效应，而不是维度本身"。
- **对论文的解读**：Fig.5 的 x 轴若真是"embedding size"，最自然的实现是**按维度截断（不重归一化）**；
  论文的风险在于：该图把"范数尺度变化"呈现为"维度效应"，容易误导读者以为高维嵌入更易被攻击。
  这一问题登记在 F11，并在 `docs/PAPER_COVERAGE.md` §10.4 中标注。

## 5. 限制

1. 论文的数据协议、ASR 公式、β、m、样本量均未给出（F11/A13），因此本实验只能做**协议假设检验**，
   不能证明论文实际用了 H2。
2. GTR 只有 768 维；d>768 的 H2 用零填充是人为构造，s>768 的行为（ASR 继续缓慢上升）与论文一致，
   但不能排除论文用了其他模型/投影。
3. ASR 采用 top-t 重合率（与 M10 一致）；论文的"ASR"若定义不同，水平差可部分解释。
4. 主网格 m=5000；m 扫描到 100000（数据重建后）显示 ASR 影响 <2 pp，因此 Fig.5 的水平差不能用 m 解释。
